# Hanska Stop IA 1.0.0

Hanska Stop IA is a Linux desktop utility for stopping supported local AI tools and their child processes under the current user. It targets Harness, Claude, Codex CLI, OpenCode, and Ollama.

## Install

On a Debian-based system, install the package with:

```sh
sudo apt install ./hanska-ai-stop_1.0.0_all.deb
```

Launch **HANSKA STOP IA** from the applications menu. Stopping an agent can interrupt an active job. The source and Debian packaging files are included.
